# studycam
캠스터디용 gui

## Features
- pyside6를 통한 gui 구현.

- 앱을 시작하면 화면에 스터디 캠 실행하기 버튼이 작게 뜨고, 그 아래에 캘린더가 크게 뜸. 스터디 캠 버튼을 누르면 스터디 캠 창으로 넘어감.

- 스터디 캠 창 설명
    - 카메라 화면이 뜨는 칸, 일주일의 시간표를 띄우는 칸, 과목별로 공부 목표를 설정하는 칸, 촬영을 시작하는 버튼, 공부 목표 시간을 설정하는 버튼으로 화면을 구성.
    - cv2를 사용해서 정해진 시간마다 스터디 캠을 찍고 종료 후 동영상화
        - 얼마만큼 배속해서 동영상을 만들지 설정 가능
        - api를 사용하여 동영상을 유튜브 등에 자동으로 업로드하는 기능
    - 스터디 플래너 및 체크박스
        - 입력한 시간표를 통해 해당 날짜의 과목들과 이후의 과목들을 각각 '복습할 과목', '예습할 과목'으로 지정해서 과목별로 띄움
        - 해당 과목을 얼마나 학습할지 텍스트로 목표량을 기록(ex:'물리1 - p13~30까지 복습하기, 수학2 - 저번 시험 범위 복습하기' 등)하고, 달성 여부를 체크할 수 있음.
        - 해당 달성 여부들을 시작 화면의 켈린더에 띄움. 
    - 공부 목표 시간 설정
        - 뽀모도로 기능: 몇분 공부하고 몇분 쉬기를 반복하는 타이머. 공부할 시간과 쉴 시간을 각각 설정 가능(ex:50분 공부할 때마다 10분 쉬기). 남은 공부 시간과 쉬는 시간을 각각 띄움. 쉬는 동안에는 캠 캡쳐 안함.
    - 배터리 보호 기능
        - 항상 카메라를 사용하는 게 아니라 필요한 때마다 카메라를 켜서 사진을 찍음
    
- 캘린더 설명
    - 스터디 플래너에서 정한 목표를 달성한 날은 해당 날짜 칸에 색을 칠함
    - 캘린더 위에 연속 목표 달성 날짜를 '30일째 공부 목표 달성 중!' 형식으로 띄움
    - 날짜를 누르면 해당 날짜의 스터디 플래너와 공부 영상을 열람 가능
