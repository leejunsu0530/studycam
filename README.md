# StudyCam

StudyCam은 공부 목표와 시간표를 관리하면서 웹캠으로 학습 과정을 기록하고, 사진을 타임랩스 영상으로 만들어 주는 Windows 데스크톱 앱입니다. 목표와 설정은 PC에 자동 저장됩니다.

## 릴리즈 버전으로 실행하기 (권장)

Python을 설치하지 않아도 됩니다. GitHub Releases에서 받은 ZIP 파일은 **압축을 푼 폴더 전체를 그대로 유지**해야 합니다.

1. Releases에서 StudyCam ZIP 파일 전체를 다운로드합니다.
2. 원하는 위치에 ZIP 파일의 압축을 풉니다.
3. 압축을 푼 폴더 안의 `StudyCam.exe`를 실행합니다.
4. 자주 사용한다면 `StudyCam.exe`의 바로 가기를 만들어 원하는 위치에 두면 편리합니다.

> `StudyCam.exe`만 따로 옮기거나, 압축을 풀지 않은 채 실행하면 필요한 파일을 찾지 못할 수 있습니다.

## 주요 기능

- **월간 캘린더**: 날짜별 목표 수·완료 수·생성 영상 수를 확인하고, 모든 목표를 마친 날과 미완료일을 색으로 표시합니다.
- **연속 달성일**: 오늘부터 이어진 공부 목표 달성 일수를 홈 화면에서 확인합니다.
- **날짜별 스터디 플래너**: 과목, 목표 내용, 복습·예습·자율 구분을 추가·수정·삭제하고 완료 여부를 체크할 수 있습니다.
- **과목 및 주간 시간표**: 스크롤 가능한 설정 창에서 과목과 수업 요일·시간을 등록하고, 시간표를 바탕으로 전날 수업의 복습 및 당일 수업의 예습 목표를 추천합니다.
- **뽀모도로 타이머**: 집중 시간과 휴식 시간을 각각 설정할 수 있으며, 휴식 시간에는 촬영이 자동으로 멈춥니다. 구간이 끝나면 알림음과 함께 타이머 글자가 반짝입니다.
- **하루 총 공부시간 목표**: 집중 시간을 하루 동안 누적하고, 설정한 총 목표시간을 자동 완료 목표로 플래너에 표시합니다. 이 목표는 실제 누적 시간으로만 완료되며 수동 수정·삭제·체크가 불가능합니다.
- **스터디 캠 촬영**: 설정한 간격으로 사진을 저장하고, 촬영이 끝나면 사진을 MP4 타임랩스 영상으로 만듭니다. 촬영을 계속하면서 미리보기만 숨길 수도 있습니다.
- **큰 시계 창**: 현재 시각, 뽀모도로, 하루 총 공부시간을 크게 표시하는 별도 창을 열 수 있습니다.
- **맞춤 설정**: 사진 촬영 간격, 타임랩스 FPS, 알림음·음량, 영상 저장 폴더, 캘린더 색상, 시작 시 최대화 및 촬영·타이머 자동 연동을 설정할 수 있습니다.
- **안전한 창 닫기**: 캘린더 창과 카메라 창 각각에 대해 닫기 방지를 설정할 수 있습니다. 방지를 끄면 닫기 버튼을 누를 때 확인 창이 표시됩니다.
- **절전 방지**: 촬영 또는 뽀모도로 진행 중에는 Windows에 절전·화면 꺼짐 방지를 요청합니다. 타이머는 실제 경과 시간을 기준으로 보정합니다.

## 사용 방법

### 1. 과목과 시간표 등록

홈 화면에서 **과목·시간표 설정**을 눌러 과목을 추가한 뒤, 각 수업의 요일과 시간을 입력하고 저장합니다.

### 2. 오늘의 목표 만들기

달력에서 날짜를 선택하고 **스터디 캠 실행하기**를 누릅니다. 오른쪽 플래너에서 과목, 목표 내용, 구분(복습·예습·자율)을 입력해 목표를 추가합니다. 시간표를 등록했다면 **시간표에서 추천 만들기**로 예습·복습 목표를 빠르게 추가할 수 있습니다.

### 3. 공부 기록 촬영

스터디 캠 화면에서 **촬영 시작**을 누르면 카메라 미리보기와 간헐 촬영이 시작됩니다. 공부를 마친 뒤 **영상 만들기**를 누르거나 창을 닫으면, 촬영한 사진으로 MP4 타임랩스가 생성됩니다.

### 4. 타이머와 하루 총 공부시간 사용

**설정**에서 집중·휴식 시간을 정한 다음 **뽀모도로 시작**을 누릅니다. 촬영 중 뽀모도로 자동 시작 옵션을 켜면 촬영 시작과 동시에 타이머도 시작됩니다. 휴식 구간에는 카메라 촬영이 중지됩니다.

**하루 총 공부 목표**에 분 단위 시간을 입력하면, 집중 구간의 시간이 하루 동안 누적됩니다. 플래너에는 자동 목표가 추가되며, 누적 시간이 목표에 도달해야 완료로 표시됩니다. 이 목표는 직접 체크하거나 수정·삭제할 수 없습니다.

### 5. 촬영 화면과 큰 시계 사용

카메라 창에서 **미리보기 숨기기**를 누르면 화면을 보지 않으면서도 촬영을 계속할 수 있습니다. **큰 시계**를 누르면 현재 시각, 뽀모도로, 하루 총 공부시간을 크게 볼 수 있으며 타이머 전환 시 반짝임도 동일하게 표시됩니다.

### 6. 실수로 창 닫는 것 방지하기

앱의 **설정 → 창 닫기**에서 **캘린더 창 닫기 방지**와 **카메라 창 닫기 방지**를 각각 설정할 수 있습니다. 방지를 켜면 해당 창의 닫기 버튼을 눌러도 창이 닫히지 않습니다. 방지를 끄면 닫기 버튼을 누를 때마다 종료 여부를 확인합니다. 큰 시계 창에는 이 설정이 적용되지 않습니다.

### 7. 기록 확인

홈 화면에서 날짜를 선택해 그날의 플래너와 생성된 영상을 확인할 수 있습니다. **선택 날짜 영상 열기**는 해당 날짜의 가장 최근 영상을 엽니다.

## 데이터 및 영상 저장 위치

- 목표, 시간표, 설정, 영상 목록: `C:\Users\사용자이름\.studycam\studycam.json`
- 사진과 타임랩스 영상: 기본값은 `C:\Users\사용자이름\.studycam\media`

저장 폴더는 앱의 **설정 → 영상·촬영본 저장 폴더**에서 변경할 수 있습니다. 중요한 기록은 별도 위치에 백업하는 것을 권장합니다.

## 카메라 문제 해결

- 카메라를 처음 사용할 때 Windows의 카메라 권한 요청을 허용하세요.
- 다른 앱이 카메라를 사용 중이면 해당 앱을 종료한 후 다시 시도하세요.
- 카메라가 없거나 권한을 허용하지 않아도 플래너와 뽀모도로 타이머는 사용할 수 있습니다.

## 개발 환경에서 실행하기

Python 3.10 이상이 설치되어 있다면 아래 명령으로 소스에서 실행할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install .
studycam
```

GitHub 저장소에서 바로 설치하려면 다음을 사용합니다.

```powershell
pip install "git+https://github.com/leejunsu0530/studycam.git"
studycam
```

## Windows EXE 빌드

개발 환경에서 폴더형 배포본을 만들려면 다음을 실행합니다. 결과물은 `dist\StudyCam\StudyCam.exe`에 생성됩니다.

```powershell
pip install ".[build]"
.\scripts\build_exe.ps1
```

단일 실행 파일이 필요하면 `.\scripts\build_exe.ps1 -OneFile`을 사용할 수 있습니다. 기본 폴더형(`onedir`) 배포는 실행이 빠르고 릴리즈 ZIP 배포에 권장됩니다.
